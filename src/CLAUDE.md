# src/ — Maven & module root

The instructions for this repo are in the **root** [`../CLAUDE.md`](../CLAUDE.md), which is what
the harness auto-loads. This directory is only the **Maven aggregator root** (`pom.xml`) and the
parent of the module dirs; it is not the project root.

Mandatory conduct and architecture rules: [`../.claude/rules/llm-conduct.md`](../.claude/rules/llm-conduct.md)
and [`../.claude/rules/architecture.md`](../.claude/rules/architecture.md). Read `llm-conduct.md`
before doing anything.

Per-module deep detail stays in each module's own `CLAUDE.md`.
